# Setup and Run Guide

This guide explains how to set up the database (with `pgvector` support) and run the AI-Powered Job Aggregator backend on your local machine.

## Prerequisites

1. **Node.js**: Ensure you have Node.js (v18+) installed.
2. **Docker**: Since the application requires the `pgvector` extension (which is complex to compile natively on Windows), you must have [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

---

## 1. Database Setup (using Docker)

The backend uses PostgreSQL combined with the `pgvector` extension to perform semantic, AI-powered hybrid searches. 

1. **Start the Database Container**:
   Open a terminal and run the following command to pull and start a PostgreSQL 17 container pre-configured with `pgvector`:
   ```bash
   docker run --name job-aggregator-db -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=job_aggregator -p 5432:5432 -d pgvector/pgvector:pg17
   ```
   *This maps the database to your local port `5432` with username `postgres` and password `postgres`.*

2. **Verify it is running**:
   ```bash
   docker ps
   ```
   You should see `job-aggregator-db` in the list of active containers.

---

## 2. Environment Configuration

1. Locate the `.env.example` file in the root of the project.
2. Copy it and rename the copy to `.env`.
3. Ensure the `DATABASE_URL` matches the Docker container settings you just created:
   ```env
   DATABASE_URL="postgresql://postgres:postgres@localhost:5432/job_aggregator?schema=public"
   ```
4. Add your OpenAI API key if you have one. If left blank, the application will automatically fall back to mock extraction and mock embedding generation to allow local development without incurring costs:
   ```env
   OPENAI_API_KEY="your_api_key_here" # Leave blank to use Mock AI mode
   ```

---

## 3. Project Initialization

1. **Install Dependencies**:
   Run the following command in the project root to install all required Node.js packages:
   ```bash
   npm install
   ```

2. **Run Database Migrations**:
   This command applies the Prisma schema to the database and automatically creates the necessary tables, indexes, and the `vector` extension.
   ```bash
   npm run prisma:migrate
   ```

3. **Seed the Database**:
   Populate the database with the initial `SUPER_ADMIN` account and the default 9 job crawling sources.
   ```bash
   npm run seed
   ```

---

## 4. Running the Application

**Development Mode**:
To run the server with hot-reloading enabled, use:
```bash
npm run dev
```

**Production Build**:
To compile the TypeScript code and run the compiled JavaScript, use:
```bash
npm run build
npm start
```

---

## 5. Verifying the Setup

Once the server is running (usually on `http://localhost:5000` unless you changed the `PORT` in `.env`), you can verify the setup by navigating to:

* **Health Check**: [http://localhost:5000/health](http://localhost:5000/health)
* **Swagger API Documentation**: [http://localhost:5000/api-docs](http://localhost:5000/api-docs)

To log in via the API (using tools like Postman, cURL, or the Swagger UI), use the credentials generated by the seed script:
* **Email**: `admin@jobaggregator.local`
* **Password**: `admin123`
